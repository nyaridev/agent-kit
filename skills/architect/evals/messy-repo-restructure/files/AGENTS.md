# AGENTS.md

A Discord bot for my server (economy, moderation, levels, fun).

## Commands

| Command | What |
|---|---|
| `pip install -r requirements.txt` | Install |
| `python bot.py` | Run (needs DISCORD_TOKEN) |

## Architecture

- Put new commands in bot.py next to similar ones.
- Use db.py for database helpers when you remember to.
- Keep everything simple, no folders.

## Git

- Commit messages in English, imperative mood.
